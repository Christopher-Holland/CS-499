# Rescue Animal Inventory System (Original Version)

## Overview
This is the **original implementation** of the Rescue Animal Inventory System.  
It was developed as a **Java-based console application** to manage a small inventory of rescue animals.  

The system supports:
- Intake of new dogs and monkeys
- Viewing available animals
- Reserving animals for service

This version is the starting point before enhancements were made for the Capstone Project.

---

## Features
- Menu-driven console interface
- Stores data in `ArrayLists`
- Basic input validation
- Supports two animal types: **Dog** and **Monkey**

---

## File Structure
- `RescueAnimal.java` – Base class with shared attributes  
- `Dog.java` – Subclass of RescueAnimal  
- `Monkey.java` – Subclass of RescueAnimal  
- `Driver.java` – Main program with the menu and logic  

---

## How to Run
1. Open the project in an IDE (such as Eclipse or IntelliJ) or compile via terminal.
2. Run the Driver.java class
